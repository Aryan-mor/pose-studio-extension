Create portrait

Add photos of the same person. Different angles and pictures give the best likeness. They are shared with a prompt that asks for a 4×2 studio portrait sheet.

Install the Chrome extension

On a computer the extension does everything for you: it attaches the images, fills in the prompt and sends it on the Gemini, ChatGPT or Grok page. Works in Chrome, Edge, Brave and Opera.

  1. Download the extension (.zip)
  2. Extract the zip to a folder you will keep (for example in Documents). Chrome reads the extension from there.
  3. Open the extensions page: then paste it in a new tab's address bar. Edge users: edge://extensions.
  4. Turn on Developer mode (top right), click Load unpacked and choose the extracted folder.
  5. Open Gemini, ChatGPT or Grok and click the Pose Studio icon in the toolbar (pin it from the puzzle-piece menu).

After an update, download the zip again, replace the folder's files and click reload on the extension.

Send to the AI site

On a computer the share menu can't reach the chat sites, so do it in three steps. Faster: install the extension and it does all this for you.

  1. Open the site
  2. Paste the images in this order (click Copy image, then press Ctrl+V in the chat box), or download them and drag them in.
  3. Paste the prompt: then Ctrl+V, and send.

About

Nothing is sent to us. There is no server or tracking. This page runs on your phone. The images and prompt go only to the AI app you choose in the share menu. The only requests it makes are for the reference pictures (from the original public galleries) and its own files.
